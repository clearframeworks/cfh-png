CFH PNG is a graphical fork of oxipng 10.2.1, commit 36f3ef8aac65ecf1761739ea2f2e530281f1312b, by the oxipng contributors: https://github.com/oxipng/oxipng .

CFH added a Windows graphical interface, a copy-only output workflow, a 256 MB raw-image limit, and a Windows installer. The optimizer remains available under the MIT License in LICENSE. The third-party license inventory included with the installer covers the dependencies in the Windows build. CFH PNG is not endorsed by the upstream project.

Source for this fork: https://github.com/clearframeworks/cfh-png
